Optional marketing assets can be placed in this folder and referenced through
Cloudflare Pages environment variables.

Suggested files:
- digitise360-logo.png
- dashboard.jpg
- mobile-app.jpg

Example variables:
VITE_MARKETING_LOGO_URL=/assets/digitise360-logo.png
VITE_DASHBOARD_IMAGE_URL=/assets/dashboard.jpg
VITE_MOBILE_APP_IMAGE_URL=/assets/mobile-app.jpg
